# 备份与恢复接口约定

主项目根目录提供以下接口，保留已有查询、CSV 导出与预算实现。

- GET /api/backup：返回完整 `{version:1, records:[...]}`，不应用筛选。
- POST /api/restore/preview：请求为原始备份对象，服务端完整校验但禁止写入；成功返回 `{valid:true,count:2,start:"2026-01-01",end:"2026-02-01"}`。空账本 count 为 0、start/end 为 null。
- POST /api/restore：仅用户明确确认后发送原始备份对象，必须再次完整校验，保留旧备份并原子替换文件和内存。成功返回 2xx JSON。
- 错误返回非 2xx `{error:"可展示的原因"}`。预览和恢复需支持5 MiB 文件对应的请求体；恢复及预览单独使用 5 MiB 限额，普通接口保留 16 KiB。两接口校验规则应一致。
- 预算为独立文件，本备份只包含全部账目；如 #6 改为包含预算，需要同步修改说明。

联调验收：取消文件选择、取消弹窗和 Escape 不请求恢复；非法 JSON、超限、错误版本、重复 ID、非法字段均不能写入；空账本需明确清空警告；确认前不 POST restore；提交中禁止重复提交和关闭；失败显示原因；恢复成功后重置筛选及分页并刷新明细、汇总、图表、预算；另验收存储失败和响应丢失场景。桌面及 375px 手机需实机验证。
